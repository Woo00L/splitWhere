# ImgSplit 本地图片切割工具

参照 [SplitImg](https://www.splitimg.com/zh) 制作的中文本地切图工作台。使用 React、TypeScript、Vite 和 Canvas；没有后端服务，图片不会上传。

## 直接使用

构建结果为 `dist/index.html`。使用 Chrome、Edge 或 Safari 打开这个文件即可，代码、样式和示例图都在同一个文件内，不需要联网或安装 Node.js。可以将它复制到其他目录或电脑。

Codex 内置浏览器不允许打开 `file://` 地址，且下载可能受限。在 Codex 中请使用下方的本地服务；保存切图建议使用普通浏览器。

## 开发和构建

开发环境建议 Node.js 24。

```sh
npm install
npm run dev
```

终端会显示本机访问地址，默认是 `http://127.0.0.1:5173/`。服务只监听本机地址。

```sh
npm test
npm run build
npm run preview
```

`npm test` 包括切割坐标、像素覆盖、编号、裁剪、边框、透明度、PNG/JPG/WebP 编码及 ZIP 解包测试。编码测试使用原生 Canvas 实现；界面另在内置浏览器完成桌面和手机宽度验证。

## 功能

- 选择文件、拖放和快捷键粘贴图片。
- 8 种预设布局、自定义 1–20 行/列、按指定像素宽高切割。
- 拖动切割线；选中后用方向键移动 1 像素，按住 Shift 移动 10 像素。
- 长图默认适合宽度显示，支持全图、100% 原始大小及缩放滑杆；在画布内滚动查看，拖线到边缘可自动滚动。预览缩放不改变导出尺寸，大图预览可按 Esc 退出。
- 反向编号，便于九宫格依次发布。
- 原始比例或 1:1、4:5、3:4、16:9、9:16 居中裁剪。
- 边框、颜色、圆角、输出宽度和有损格式画质设置。
- 实时结果预览、单张下载、复制为 PNG、全部打包 ZIP。
- 打包完成后提供可再次点击的保存链接。

## 处理边界

- 支持 JPG、PNG、WebP、GIF、BMP、AVIF，具体解码能力取决于浏览器。
- 动图在读取时冻结为静态画面，不保留动画。
- 输入文件不超过 80 MB、8000 万像素，单边不超过 32768 像素。
- 每次最多 400 个切块。按像素切割时，尾部不足一块的区域会保留。
- 单张输出不超过 3200 万像素、单边不超过 16384 像素；ZIP 总输出不超过 1.2 亿像素。
- PNG 和 WebP 支持透明背景；JPG 使用所选底色填充透明区域。
- 复制功能需要浏览器支持剪贴板写入并允许访问，受限时可使用下载。
- 图片和设置不会自动保存，关闭或刷新页面前请下载结果。

示例插画来自参考站的公开示例 `https://www.splitimg.com/imgs/samples/panorama.webp`，已打包到本地；使用时不会请求原站。页面底部保留参考来源链接。
